## 🚀 Hướng Dẫn Chạy Nhanh (Web + Expo Go)

### 1. Chạy Web Quản trị & Mobile PWA
```bash
npm install
npm run dev
npm run build
```

### 2. Chạy Native Mobile App trên **Expo Go** (`mobile-expo/`)
```bash
cd mobile-expo
npm install
npx expo start --port 8081
```
- Mở ứng dụng **Expo Go** trên iOS / Android và quét mã QR hiển thị trên terminal (hoặc truy cập `exp://<IP-LAN>:8081`).

## 📊 Tích Hợp Google Sheets (`google-sheets/Code.gs`)

1. Mở bảng tính Google Sheets mới → vào **Tiện ích mở rộng (Extensions)** → **Apps Script**.
2. Sao chép nội dung file [`google-sheets/Code.gs`](./google-sheets/Code.gs) dán vào trình biên tập và chạy hàm `setupPhuonghihiDatabase()` (hệ thống tự động khởi tạo toàn bộ 8 trang tính chuẩn cho Cửa hàng phuonghihi).
3. Chọn **Triển khai (Deploy)** → **Ứng dụng web (Web App)** và dán URL vào mục **Cài đặt > Tính lương & Sheets** trên giao diện Web.
